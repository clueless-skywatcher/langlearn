Nouns II - Plurals

1. In German there are seven ways to constructing the plural

1.1 Word stays the same.
E.g. der Lehrer -> die Lehrer
1.2 Mostly stays the same, but an umlaut is added somewhere in the word
E.g. der Vogel -> die Voegel
1.3 Adding an -s to the end
E.g. das Baby -> die Babys
1.4 Adding an -e to the end
E.g. der Jahr -> die Jahre
1.5 Adding an -e to the end, and an umlaut transformation
E.g. der Stuhl -> die Stuehle
1.6 Adding an -er to the end, and maybe an umlaut transformation
E.g. das Kind -> die Kinder, das Tal -> die Taeler
1.7 Adding -n (for words ending with -e, -el or -en) or -en
E.g. die Frau -> die Frauen, die Kartoffel -> die Kartoffeln

2. There is no general rule for figuring out the plural of a noun. So try to remember the plural of the noun along with its gender.
